THE PLANNER PRINT PREP GUIDE

How to print planner PDFs: size, duplex and test prints

Start with your own PDF in reading order. Each source page must contain one insert; the tool does not split two-up spreads.

1. Choose a file, size and paper

Choose a PDF or try the seven-page example. Select Letter or A4 outer paper and A5, A6, Half Letter or a custom portrait trim. Actual size preserves the source dimensions; Fit whole design scales uniformly and leaves blank space when proportions differ. A design that does not fit is blocked, never silently cropped.

2. Pair the sides

Single-sided output uses every source page once without padding. Duplex pairs pages in reading order and adds a final blank if needed. If source page 1 is a back, choose that explicitly to add a blank front. Existing blank pages stay. Inspect every sheet in the preview.

For automatic duplex, match long or short edge in the printer dialog. For manual duplex, mark two sheets A/B and test their feed and stack direction. Download Fronts and Backs separately; reverse Backs only if your tested path requires it.

3. Test, measure, then adjust

Download the test PDF even without choosing a source file. Print at 100% / Actual size. Measure both 100 mm rulers. A wrong ruler length is a scaling problem; fix paper and print settings first. Repeated stable displacement can be compensated, while random shifts and skew cannot.

View the back upright. If its artwork is 2 mm right and 1 mm down, enter +2 and +1. The tool applies left 2 mm and up 1 mm. Recheck whenever the paper, size, flip edge or print path changes. You can skip a test; the output remains marked not test-printed in the guide.

Three common scenarios

A5 design on Letter

Choose A5 trim, Letter paper and Actual size. Inspect the page pairs, print one test sheet, then cut along the external trim marks.

A5 design into Half Letter

Choose Half Letter trim and Fit whole design. The design scales to about 94.39%, preserving its proportions with vertical blank space. A5 and Half Letter are not interchangeable.

A repeatable back-side shift

Use the test rulers to rule out scaling. Measure the same stable shift from the upright back, enter it, print again and compare. Stop chasing offsets if the shift varies.

4. Save and print

Download the print-ready PDF. File sharing is offered only where the browser reports support; cancelling leaves the generated result available. Use Download or Open PDF as a fallback. A download request is not proof of saving, printing or physical alignment.

Print with the same paper, 100% / Actual size and flip edge. Do not skip generated blank pages. iPad and physical printing remain unverified for this release; this tool cannot control AirPrint settings.
