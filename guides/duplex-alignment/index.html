A LITTLE PREPARATION
BEFORE THE FIRST SHEET

THE PLANNER PRINT PREP GUIDE

Double-sided printing not lining up? Check scale and back offset

A wrong page size, a repeatable back-side shift and random feed errors need different responses. Start with one test sheet before changing the offset.

1. Check the size before moving the back

Download the test PDF, even without choosing a source file. Print on the selected paper at 100% / Actual size using the flip edge you intend to use. Measure both the horizontal and vertical 100 mm rulers.

If either ruler is the wrong length, check the reader’s scaling, selected paper and print path. Moving the back cannot fix a scaled design. Avoid adding another Fit-to-page step after exporting a PDF already arranged for that sheet.

What you observeNext check
The ruler is not 100 mmPaper and scaling settings first
The same back-side shift repeatsMeasure and enter a fixed X/Y offset
Shift varies or the sheet is skewedPaper, feed, driver and printer limits

2. Measure a consistent shift with the back upright

View the back in its reading orientation. Measure how far its artwork is from the intended frame. Enter the observed error, not the movement you want: right and down are positive, left and up are negative.

For example, if the back is consistently 2 mm right and 1 mm down, enter +2 for Back is shifted right and +1 for Back is shifted down. The tool moves the back left 2 mm and up 1 mm. It also accounts for the selected short-edge rotation in the output PDF.

Offset inputs support −10 to +10 mm on each axis. If a value pushes content beyond the planned safe area, export is blocked. Do not reduce a margin only to hide a real printable-area problem. You can undo or reset the offset.

3. Reprint and compare using the same path

Print another test sheet with the same paper, reader, driver, scale and flip edge. Measure again before printing the full file. Changing paper, trim, flip edge or the print path means the earlier test may no longer apply; the tool asks you to recheck relevant setting changes.

Skipping a test still lets you export, but the guide remains marked not test-printed. Clicking I checked a test print records your report; it is not a measurement or independent proof of physical alignment.

When back-side offset correction will not help

A single X/Y value cannot correct random shifts, skewed or rotated feeding, unsupported duplex paper, scaling errors or borderless limitations. Check the printer specifications, paper handling and driver. Stop chasing a number if the error changes from sheet to sheet.

The browser cannot force a particular AirPrint or driver setting. iPad/iPhone, macOS, system sharing and physical printing remain unverified for this release; local PDF checks do not replace a test on your own printer.

Read the two preview directions correctly

Front & back shows both sides upright. Raw output PDF direction shows short-edge backs intentionally rotated 180 degrees. See-through alignment reflects the upright back into the front view, so its text appears mirrored as it would through paper. These views explain file layout, not real feed accuracy.
