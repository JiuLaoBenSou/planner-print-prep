THE PLANNER PRINT PREP GUIDE

About Planner Print Prep

Made by Foster Fei for people who have a PDF they like, and would rather print it than learn a full imposition application.

Keep the design. Change the fit.

Choose an existing multi-page PDF, place one insert on each side of A4 or Letter paper, check the page pairs, and prepare a test print. The output is a static print copy; it is not a planner editor.

Free to use

The core tool has no account, watermark, export cooldown or payment requirement. If it helps, you may support the project on Ko-fi. That external service has its own privacy terms. There are no ads in this version.

Future Plus edition

Batch processing and named print profiles are planned for a future Plus edition. Plus is not available to purchase, and this site currently has no paid checkout.

Honest limits

Fixed back-side translation can be compensated. Random feeding, skew, printer margins and driver settings cannot. iPad/iPhone, macOS and physical printer paths have not yet been verified. Desktop automated results are not a promise about every PDF or printer.

Only use PDFs you have the right to process. This tool is independent of planner brands and printer manufacturers.
