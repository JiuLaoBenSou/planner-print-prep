2026 / FIVE DIRECTIONS

历史方案比较 / E 已选为默认界面

给不同的日常，
留一点不同的空间。

五套界面都能导入 PDF、核对页序、试印和导出。已采用 E 为默认界面，其他方向在此保留为本地历史预览。

A–C 是三种使用情境的设计假设；D 采用撞色文具风；新增 E 按所选 GitHub 规范，采用更紧凑的白灰工作台。所有方向均不代表已验证的职业、年龄或购买人群统计。

E / GitHub 风格 · NEW白灰 · 紧凑 · 功能优先

把注意力留给文件。

遵循所选GitHub风格规范：系统无衬线、白灰背景、蓝色交互、6px圆角和细边框，减少首页装饰，直接进入打印工作台。

  • 小标题与紧凑表单，文件和参数更集中
  • 无衬线字体，清晰的蓝色键盘聚焦环
  • 保留真实预览、试印、导出与设置功能
体验 E · GitHub style ↗
D / 撞色文具 · NEW鲜明 · 几何 · 有活力

NEW DIRECTION / PAPER POP

计划，可以有点响亮。

荧光绿与亮青色块，大字海报标题，粗黑边框和方形按钮。更像一张鲜明的文具海报。

  • 粗体无衬线，搭配等宽说明
  • 明亮色块、几何贴纸与硬边阴影
  • 设置分卡，正反预览使用亮青底板
体验 D · Paper pop ↗
A / 教学工作台清楚 · 直接 · 高对比

先把事情说清楚。

缩短首页，放大设置标签和安全提示。适合希望尽快完成打印准备的人。

  • 紧凑工作台，设置在左、预览在右
  • 无衬线标题，高对比网格
  • 重点突出纸型、双面与试印
体验 A · Teaching desk ↗
B / 学习笔记轻快 · 纸感 · 更有节奏

让开始轻一点。

借用笔记本和纸页的节奏，让打印工具少一些专业软件的距离感。

  • 预览在左、设置在右
  • 纸张底色、斜体标题、虚线标记
  • 轻松文案，仍保留直接数值输入
体验 B · Study notebook ↗
C / 家庭纸品温暖 · 克制 · 舒缓

日常也值得慢慢整理。

温暖的纸品感与柔和面板，适合家庭日程、生活记录等安静的使用场景。

  • 舒缓的留白与较柔和的面板
  • 暖奶油、鼠尾草绿、自然圆角
  • 逐步引导，保留所有核心功能
体验 C · Everyday paper ↗

怎么比较

进入任一方案后，页顶按钮可直接切换外观，保留当前文件、设置和已生成结果。返回这个比较页会离开当前工具页，请先保存需要的 PDF。

建议用同一份 PDF 试三件事：找出纸型与成品设置；确认某张纸的正反页；导出试印文件。无需按职业或年龄给自己选版。

已选择 E 为主工具默认界面。主工具目前免费。收费是另行规划的增强功能方案，这里没有支付接入或付费功能承诺。
